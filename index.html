Cloud Sync: TradeForge Account

Local-only mode. Your devices do not share data until cloud sync is configured.
Cloud Sync uses a private Supabase project with email/password sign-in. You control the database. Your Supabase project URL and public/publishable key are not passwords, but never enter a service-role or secret key here.

Your TradeForge Sign-in

Sync & First-Time Setup

When signed in, TradeForge syncs open positions, Planner inputs, Evaluation Dashboard, and Trade Review between your devices. Changes are saved locally first, then uploaded automatically while online.

Not signed in.
First time: on the device holding your current trades, select Use This Device as Starting Copy. On the laptop and phone, sign into the same TradeForge account and select Load Cloud Data if needed. Once initialized, changes sync automatically. Uploading your starting copy replaces the cloud snapshot, so do that only once.
A sync conflict stops uploads rather than silently overwriting changes from another device. Select Load Cloud Data to resolve it (export a backup first if you need to preserve the local copy). Local changes made while offline can conflict with remote changes when you reconnect.
Setup steps and database security rules are in CLOUD-SETUP.txt and supabase-setup.sql included with this release. You do not need to edit the TradeForge app code.
